# Go Password Generator

Консольный генератор криптографически стойких паролей на Go. Для получения случайных данных используется пакет [`crypto/rand`](https://pkg.go.dev/crypto/rand), подходящий для генерации паролей.

## Возможности

- настройка длины пароля;
- генерация нескольких паролей за один запуск;
- включение и отключение строчных и прописных букв, цифр и специальных символов;
- гарантия наличия хотя бы одного символа из каждого включённого набора;
- вывод только паролей в стандартный поток вывода, что удобно для shell-скриптов.

## Требования

Go 1.22 или новее.

## Запуск

```bash
go run .
```

По умолчанию программа создаёт один пароль длиной 16 символов, используя все доступные наборы.

Посмотреть справку:

```bash
go run . --help
```

## Настройки CLI

| Флаг | Значение по умолчанию | Описание |
| --- | ---: | --- |
| `--length`, `-l` | `16` | Длина каждого пароля |
| `--count`, `-n` | `1` | Количество паролей |
| `--lowercase` | `true` | Использовать строчные латинские буквы |
| `--uppercase` | `true` | Использовать прописные латинские буквы |
| `--digits` | `true` | Использовать цифры |
| `--symbols` | `true` | Использовать специальные символы |
| `--version` | `false` | Показать версию программы |

Логический флаг отключается с помощью значения `false`, например `--symbols=false`.

## Примеры

Создать пароль длиной 24 символа:

```bash
go run . --length 24
```

Создать пять паролей:

```bash
go run . --count 5
```

Создать пароль без специальных символов:

```bash
go run . --symbols=false
```

Создать цифровой PIN-код длиной 8 символов:

```bash
go run . -l 8 \
  --lowercase=false \
  --uppercase=false \
  --symbols=false
```

## Сборка

```bash
go build -o passwordgen .
./passwordgen --length 32 --count 3
```

Установка через Go:

```bash
go install github.com/qopq1366/go-passwordgenerator@latest
```

## Замечания по безопасности

- Каждый пароль генерируется из случайных данных операционной системы через `crypto/rand`.
- Не передавайте сгенерированный пароль как аргумент другой команды, если его можно передать через стандартный ввод: аргументы процесса иногда доступны другим пользователям системы.
- Не сохраняйте пароль в истории командной оболочки без необходимости.
